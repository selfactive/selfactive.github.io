プライバシーポリシー

対象：ChainLab（iOS）および本サポートサイト
制定・最終更新日：2026年10月8日

selfactive（以下「開発者」）は、ChainLab と本サイトにおける利用者情報を、以下のとおり取り扱います。

1. 盤面・設定などの端末内データ

作成・保存した盤面、アプリの設定、広告非表示の購入状態は、機能の提供と状態の保持のために端末内へ保存します。開発者が管理するサーバーへ、盤面や設定を自動送信する機能はありません。ChainLab 独自のアカウント登録は不要です。

2. 画像の保存・共有

利用者が画像保存を実行したときに、盤面の画像を端末へ保存します。OS によって写真ライブラリなどへの権限を求める場合があります。共有を実行した場合は、利用者が選んだアプリやサービスへ画像を渡します。共有先での取り扱いには、そのサービスのポリシーが適用されます。

3. 広告配信

ChainLab は、Google LLC が提供する Google AdMob（Google Mobile Ads SDK）を使用して広告を表示します。広告サービスは、広告配信・効果測定・不正防止・診断などのため、IP アドレス、IP アドレスから推定されるおおよその位置、端末やアプリに関する識別子、広告表示・操作情報、クラッシュ情報や性能情報などを取得・処理する場合があります。実際の取り扱いは、OS、権限、地域、同意の状態、広告サービスの設定により異なります。

必要な地域・条件では Google の同意管理機能を通じて選択肢を表示します。アプリ内に「広告のプライバシー設定 / Ad privacy」が表示される場合は、そこから選択を変更できます。端末のプライバシー設定もご確認ください。

  • Google プライバシーポリシー
  • Google のサービスを使用するサイトやアプリから収集した情報の使用

4. アプリ内購入

広告非表示の購入・決済は Apple の App Store を通じて行われます。アプリは商品識別子や購入・復元の結果などを利用して購入状態を確認し、機能を有効化します。開発者はアプリを通じてクレジットカード番号などの決済情報を取得しません。決済に関する情報は Apple のポリシーに従って取り扱われます。

Apple プライバシーポリシー

5. お問い合わせ情報

X などでお問い合わせいただいた際は、アカウント名、連絡内容、任意で提供された端末情報や画像などを、回答、不具合の調査、サービス改善のために利用します。機微な情報や決済情報の送付はお控えください。X 上の情報は X のポリシーにも従います。

X プライバシーポリシー

6. 本サイトへのアクセス

本サイトは GitHub Pages で公開しています。配信・運用・セキュリティのため、ホスティング提供者が IP アドレスなどのアクセス情報を取り扱う場合があります。本サイトには、開発者が追加したアクセス解析ツール、広告、入力フォームはありません。

GitHub プライバシーステートメント

7. 第三者による取り扱い

広告、決済、ホスティング、問い合わせ・共有先のサービスによる情報の取り扱いには、各提供者のポリシーが適用されます。これらのサービスにより、利用者の居住国外で情報が処理される場合があります。開発者が直接受け取ったお問い合わせ情報は、本人の同意がある場合、対応に必要な委託を行う場合、法令に基づく場合などを除き、第三者へ提供しません。

8. 保存期間・削除・ご相談

端末内の盤面はアプリの削除機能などで削除できます。アプリを削除すると端末内のアプリデータが失われる場合があります。写真ライブラリや共有先へ保存した画像は、それぞれの保存先で削除してください。購入履歴は App Store 側にも保持されるため、アプリの削除では消去されません。

開発者が受け取ったお問い合わせ情報は、対応と調査に必要な期間保管し、不要になった情報は削除するよう努めます。開示・訂正・削除などのご相談は、以下の連絡先で受け付けます。外部サービスが管理する情報については、当該サービスの窓口をご利用ください。

9. ポリシーの変更

アプリの機能や利用するサービスの変更に応じて、本ポリシーを更新します。変更内容と更新日は本ページに掲載し、必要な場合は適切な方法でお知らせします。
